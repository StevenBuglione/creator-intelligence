# Contributing

Use Node 24.19.x, pnpm 11.25.0 and local PostgreSQL/Redis. Read AGENTS.md and the setup guide.
Run `pnpm verify` with isolated test credentials before proposing a change. Keep secrets,
runtime data and Google audit material outside Git. Label fixture versus real-provider evidence.

Update the feature coverage ledger and document external gates honestly. Preserve exact owner
authorization and default-disabled additional metrics. Do not add scraping, quota bypass,
unapproved analytics or unexpected publishing. Contributions to this repository are under MIT.
