Install the actual implementation

The repository includes the MCP server, API, worker, review UI, database layer, local blueprint export and tests. Use Node.js 24.19.x, pnpm 11.25.0, PowerShell 7 and Docker Compose for the maintained Windows setup.

git clone https://github.com/StevenBuglione/creator-intelligence.git
cd creator-intelligence
pnpm install --frozen-lockfile
./scripts/init-local.ps1 -OwnedChannelId 'YOUR_CHANNEL_ID' -GoogleProjectNumber 'YOUR_PROJECT_NUMBER'
./scripts/with-local-env.ps1 docker compose up --build -d
./scripts/copy-owner-password.ps1

Replace the identity placeholders with your values. Open http://localhost:4310 and sign in with the generated owner password. Follow the setup guide for your API key, read-only OAuth client, channel consent and private credential storage.

Register one connection with Claude Code

pnpm build
$launcher = (Resolve-Path ./scripts/mcp-launch.ps1).Path
claude mcp add --scope user creator-intelligence -- pwsh -NoProfile -File $launcher

The local services must be running. The launcher loads your MCP token from private storage. A managed client may need administrator allowlisting. Authenticated Streamable HTTP is also available at http://localhost:4312/mcp; choose one transport.

Bring your own Google project, credentials and channel authorization. The source license does not provide access to the developer’s deployment, quota or Google approval.

Read the tool reference and argument examples. Source text is treated as untrusted data. An MCP request cannot authorize its own draft write. Blueprint export returns the requested revision without sending it to another service.

One MCP, local services behind it

TypeScript services run with Docker Compose: Fastify API, Next.js review UI, background worker, MCP transport, PostgreSQL and Redis. The default ports bind to loopback. Secrets stay outside Git; Google tokens are encrypted at rest.

No mandatory paid cloud dependency. Optional AI clients may process requested data under their own terms and settings. The project’s MIT license covers its code; dependencies and container images have their own licenses, described in third-party notices.

A release candidate with visible limits

The repository includes the feature ledger, acceptance plan, automated tests and actual verification results. The 151-feature backlog is a plan, not a list of completed capabilities.

  • Owner OAuth and Claude registration require installation-specific setup and verification. Source distribution does not share the maintainer’s credentials.
  • Custom scores and extended public-statistical retention remain disabled pending the relevant accepted YouTube authorization and implementation.
  • No scraping, quota bypass, invented competitor analytics or automatic YouTube publication.
  • The app enforces versioned privacy/terms acceptance and optional MCP sharing. Google audit review requires deployment-specific evidence and an appropriate reviewer-access arrangement.
