# Security

Report vulnerabilities using this repository's GitHub private vulnerability reporting feature.
Do not post credentials, tokens, private analytics, addresses or exploit details in a public issue.
For documentation questions, use Issues without personal data.

This release is intended for a trusted single-owner local machine. Bind services to loopback,
protect private environment files and backup keys, and keep Docker administrators trusted.
The source license grants no rights to the maintainer's credentials, Google project or deployment.
